# Modelo de ADR

Use este modelo para registrar decisões de arquitetura. Arquivo: `NNN-titulo-curto.md`. Decisões relevantes são registradas conforme a regra 5 do AGENTS.md.

## Contexto
Por que a decisão é necessária (fatores, restrições, o que motiva).

## Opções consideradas
- **Opção A** — descrição.
- **Opção B** — descrição.

## Escolha
O que foi decidido (e o estado: pendente de aprovação / aprovada).

## Motivo
Justificativa objetiva da escolha e consequências (positivas e negativas aceitas).
